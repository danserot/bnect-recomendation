# Проверка прототипа · 23.10.2026

Текущий интерфейс упрощён до каталога, сведений выбранного тендера и пяти похожих закупок. Профили, вкладки и расширенные фильтры на экране отсутствуют.

Проверено:

- Production-сборка frontend и backend, TypeScript.
- 21 unit-тест и 9 интеграционных тестов с настоящими E5 embeddings и PostgreSQL/pgvector.
- GET похожих закупок без профиля: текст выбранного тендера, исключение его ID, top-5 по косинусу.
- Совпадение pgvector-рейтинга с независимым расчётом косинуса в 384 измерениях.
- Сохранение embeddings для неизменившегося текста, инвалидирование после изменения текста, отказ при несовместимой версии.
- Согласованный снимок при параллельном изменении данных.
- CSV dry-run не добавил записи: в БД осталось 96 demo-тендеров, все 96 проиндексированы.
- В настоящем браузере: каталог → тендер «Печать информационных буклетов» → пять похожих → переход в «Изготовление корпоративных каталогов» → новая подборка.
- Мобильный экран 360 px; сведения и похожие закупки доступны без горизонтального переполнения страницы.
- Понятные ошибки недоступной БД и отсутствующей модели, без фиктивного поиска.

Данные синтетические. Производительность на большом реальном наборе и подключение внешней базы поставщиков не проверялись. Тесты используют локальную demo-базу; временные изменения в интеграционных проверках восстанавливаются в `finally`.
