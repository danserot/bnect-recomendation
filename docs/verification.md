# Проверка проекта

## Рефакторинг и очистка · 26.10.2026

- TypeScript, форматирование и Docker-сборка прошли. Все три контейнера имеют статус `healthy`.
- 65 unit-тестов прошли, включая проверки календарных границ и однократного чтения размеров Excel.
- 12 интеграционных тестов рекомендаций с настоящей E5-моделью и 6 интеграционных тестов аналитики прошли в отдельной временной БД на синтетических данных. Тестовая БД удалена после выполнения.
- Дополнительно проверены пакетный upsert с повторными номерами, сохранение ID, dry-run и один SELECT для неизменившегося пакета.
- В браузере проверены поиск без совпадений, очистка поиска, регион и пагинация каталога, выбор закупки и автоматический регион аналитики, дополнительный регион сравнения, сброс фильтров, карта и план внедрения. Ошибок JavaScript не обнаружено.
- Проверены ширины 1280 и 390 px; горизонтального переполнения страницы нет. На сохранённых снимках строки и цены скрыты.
- В Docker подтверждены права пользователя `node` на запись в каталог отчётов; отчёты сохраняются в отдельном volume `bnect_reports`.

После устранения повторного обхода таблицы в ExcelJS и запросов на каждую строку повторный импорт того же локального файла с 13 007 тендерами занял около 1,5 с вместо 48 с. Это сравнение двух запусков по временным отметкам журнала на текущем компьютере, с готовой БД и без новых embeddings; оно не является нагрузочным тестом или обещанием времени для других файлов.

Удалены четыре неиспользуемых компонента старого интерфейса, их клиентские API-методы и UI-экспорты, 841 строка мёртвого CSS и 37 старых временных журналов/снимков. Рабочие Excel, кеш модели, БД и полезные локальные отчёты сохранены. Описание новых модулей — в [архитектуре](architecture.md).

## История проверки рекомендаций · 23.10.2026

Это результаты проверки версии от 23.10.2026 на синтетических данных. Они сохраняются как история и не описывают текущий каталог, число тестов или навигацию. Актуальные команды запуска и проверок — в [README](../README.md); последующие проверки — в [отчёте аналитики](purchase-analytics-verification.md).

На момент проверки интерфейс состоял из каталога, сведений выбранного тендера и до пяти похожих закупок. Профили, вкладки и расширенные фильтры на экране отсутствовали.

Проверено:

- Production-сборка frontend и backend, TypeScript.
- 21 unit-тест и 9 интеграционных тестов с настоящими E5 embeddings и PostgreSQL/pgvector.
- GET похожих закупок без профиля: текст выбранного тендера, исключение его ID, top-5 по косинусу.
- Совпадение pgvector-рейтинга с независимым расчётом косинуса в 384 измерениях.
- Сохранение embeddings для неизменившегося текста, инвалидирование после изменения текста, отказ при несовместимой версии.
- Согласованный снимок при параллельном изменении данных.
- CSV dry-run не добавил записи: в БД осталось 96 demo-тендеров, все 96 проиндексированы.
- В настоящем браузере: каталог → тендер «Печать информационных буклетов» → пять похожих → переход в «Изготовление корпоративных каталогов» → новая подборка.
- Мобильный экран 360 px; сведения и похожие закупки доступны без горизонтального переполнения страницы.
- Понятные ошибки недоступной БД и отсутствующей модели, без фиктивного поиска.

Данные этой проверки синтетические. Производительность на большом реальном наборе и подключение внешней базы поставщиков тогда не проверялись. Интеграционные проверки восстанавливали временные изменения в `finally`.
