# Проверка аналитики закупок, 25.10.2026

## Автоматические проверки

- `npm test`: 44 unit-теста — числа с пробелами и запятыми, Excel/текстовые даты, расчёт единичной цены, ошибки строк, дубли, сопоставимость, существующие рекомендации и география.
- `npm run test:analytics`: 5 интеграционных проверок с настоящим PostgreSQL в отдельной временной схеме, которая удаляется после тестов. Проверены пустая БД, dry-run, повторный импорт, серверная пагинация, расчёт по всей выборке, исключение всех строк выбранного документа, регионы, единицы, валюты, НДС, виды цены, даты и арифметическая средняя при неполном количестве.
- `npm run test:integration`: 10 проверок настоящей локальной E5/pgvector, включая рекомендации выбранного региона, PCA и сохранение embeddings. Устаревшие предположения тестов о ровно пяти рекомендациях, демонстрационной отрасли первого результата и отсутствии буквального `%` заменены проверками текущего содержимого БД и контрактов. Прежняя независимая проверка полного косинусного ранжирования сохранена.
- `npm run typecheck` и `npm run build`: backend и frontend собираются.

## Edge

Использован установленный Microsoft Edge через Playwright CLI. Для интерактивных проверок создан отдельный локальный стенд и временная схема БД с синтетическим Excel. Реальные закупки не включались в скриншоты. Отчёт большого импорта на тестовом стенде подменялся `null`; сами импорт, каталог и расчёты работали с настоящим API/PostgreSQL.

Проверены пустой каталог, предпросмотр Excel и добавление записей, навигация, выбор закупки, скрытие третьего показателя без дополнительной группы, поиск и отсутствие результатов, фильтры периода/товара/региона, пагинация, подсказки графика, разрывы данных, ошибка 503 и повторная попытка. При смене фильтров и ошибке прежняя средняя отсутствует в DOM.

Контрольная синтетическая выборка: выбранная цена 120, аналоги 100 × 10 и 200 × 30. Основная средняя 175, отклонение −31,43%; дополнительный регион 300. Выбранный документ, другой товар, валюта, единица, НДС, вид цены и дата вне периода не попадают в основную выборку.

Проверены desktop 1440 px и мобильный экран 390 px: показатели над графиком, таблица прокручивается внутри контейнера, страница не имеет горизонтального переполнения, меню не накладывается на заголовок. Проверка ресурсов страницы не обнаружила внешних запросов.

## Реальный локальный файл и конфиденциальность

Предоставленная большая выгрузка прочитана локально, прошла dry-run и импортирована отдельной транзакцией. Расчёт для одной реальной сопоставимой группы независимо проверен SQL без вывода названий, цен и контрагентов. Серверная выдача ограничивает размер страницы; перечень товаров ограничен и поддерживает отдельный поиск.

Прямые запросы Vite к обоим Excel, `.env` и файлу кеша модели возвращают HTTP 403. Настоящая E5 успешно сформировала вектор из синтетического текста, когда `globalThis.fetch` был принудительно заблокирован; сетевых попыток не было. Файлы Excel игнорируются Git и отсутствуют в текущем индексе, но прежний `tenders.xlsx` остаётся в старой истории, включая локальную ссылку на удалённую ветку. Подробности и границы защиты — в [privacy.md](privacy.md).

Это функциональные локальные проверки. Нагрузочный тест множества одновременных пользователей, внешнее развёртывание и очистка удалённой Git-истории не выполнялись. Валюта KZT подтверждена пользователем; скриншот-образец не был предоставлен.

## Обновление: полный график или объяснение

Добавлены 8 проверок правила полноты и серверного HTML: отсутствие выбранной закупки/цены/даты, одна точка, пропуски в начале, середине и конце периода, неполная дополнительная группа, строки без даты и полный ряд. Неполный ряд не создаёт SVG и легенду; разбор содержит выбранную закупку и таблицу интервалов. Интеграционная проверка подтверждает точное ограничение крайних интервалов датами периода.

Предыдущие проверки отображения отдельных точек и разрывов относятся к ранней версии интерфейса. Теперь применяется правило «не менее двух заполненных интервалов и ни одного пропуска во всех включённых группах». Блоки загрузки Excel и отчёта импорта ранее удалены со страницы; локальный импорт и его API сохранены.

В Edge на отдельном синтетическом стенде проверены: отсутствие SVG и легенды при заполнении 2 из 7 интервалов, разбор с таблицей всех семи интервалов, отсутствие горизонтального переполнения при ширине 390 px, полный основной ряд из 7 интервалов, скрытие графика при неполной дополнительной группе и отображение двух полных рядов. Реальные закупки в скриншоты и результаты проверки не включались.
