# Источники данных

Реальный CSV/XLSX и реальная база поставщиков не предоставлены. Изображение таблицы не используется как база поставщиков. В `backend/src/data/demo.ts` описаны 96 синтетических тендеров из 12 сфер и пять демонстрационных профилей компаний. Все тендеры имеют `source: "demo"`, номера `DEMO-*` и фиксированный seed `20261023`. Синтетические статусы и сроки рассчитаны относительно `2026-10-23T09:00:00.000Z`, а не текущих часов компьютера. Часть записей намеренно имеет неизвестную доступность и неизвестный регион.

`tenders.example.csv` — маленький **вымышленный образец формата импорта**, а не выгрузка действующих закупок. После импорта его `source: "import"` описывает способ загрузки; номера `SAMPLE-*` и названия сохраняют демонстрационную природу примера. Полный набор для запуска создаётся командой seed.

CSV принимается в UTF-8 с BOM или без него, разделитель `;` либо `,`, значения с разделителями заключаются в двойные кавычки. Обязательные заголовки:

```text
№ тендера;Наименование тендера;Регион;Дата создания;Сфера (группа);Сфера деятельности;Способ закупки;Вид закупки
```

Адаптер `parseTenderCsv` проверяет строки через Zod и возвращает `tenders`, `errors`, `duplicates`, `totalRows`. Ошибка содержит номер строки, поле и сообщение. Форматы дат: `ДД.ММ.ГГГГ`, `ГГГГ-ММ-ДД`, ISO timestamp с часовым поясом. Невозможные календарные даты отклоняются. В CSV могут присутствовать дополнительные колонки `Описание`, `Статус` (`open`, `closed`, `Открыт`, `Закрыт`) и `Срок подачи заявок`. Без них статус и дедлайн не выводятся из даты создания. Доступность участия неизвестна.

Повторный `externalNumber` обновляет существующую запись при сохранении. Если номер повторяется в одном файле, применяется последняя **валидная** строка, а номера обеих строк перечисляются в `duplicates` с политикой `last-valid-row-wins`. Невалидный дубль не стирает валидную запись. ID импортированной записи детерминирован по `externalNumber`; операция dry-run использует тот же парсер без записи в БД. Политику сохранения реализует сервис импорта, сам адаптер не обращается к БД.

Справочник регионов сопоставляет полное нормализованное имя или алиас: `Астана`, `г. Астана` и `Нур-Султан` дают `astana`; `Алматы` и `Алматинская область` остаются разными регионами. Неизвестное/пустое имя даёт `regionId: null`. Такая запись доступна в режиме «Все регионы» и исключается при ограничении по региону. Исходное значение не заменяется предположением о ближайшем известном регионе.

Профили поставщиков — отдельный синтетический источник с текстом специализации, сферами, видами работ и географией. Интеграция реальной БД поставщиков не выполнена и её схема не предполагается.
